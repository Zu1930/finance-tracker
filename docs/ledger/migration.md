# Переход на балансы из журнала: запуск миграции

Запускает владелец после мержа и бэкапа (`docs/restore.md`). Сессия Claude к production доступа не имеет.

## Порядок

Схема `drizzle/0006_ledger.sql` только добавляет поля и таблицы, поэтому её можно применить заранее: старый код
продолжит работать. Перевод данных выполняется сразу после деплоя. Пока бюджет не переведён, траты нельзя записать
с общего счёта: у него нет владельца.

```sh
set -a; source .env.cutover.local; set +a      # DATABASE_URL_UNPOOLED production, как в docs/cutover.md
export PRODUCTION_DB_HOST="$(node -e 'console.log(new URL(process.env.DATABASE_URL_UNPOOLED).hostname)')"

# 0. Бэкап (docs/restore.md)
# 1. Схема — до или сразу после мержа
npm run db:migrate -- --production
# 2. Пробный прогон: ничего не пишет, показывает сводку и предупреждения
npm run db:migrate-ledger -- --dry --production --out ledger-dry.json
# 3. Перевод (день перехода — сегодня; можно задать --day YYYY-MM-DD)
npm run db:migrate-ledger -- --production --out ledger-done.json
```

Повторный запуск безопасен: переведённые бюджеты (`households.ledger_since` задан) пропускаются.

## Что делает

- Счёт: `initial` = записанный остаток, `initial_at` = день перехода. Общий счёт становится личным счётом
  владельца семьи. У каждого человека выбирается основной счёт: уже отмеченный или с наибольшим остатком.
- Все существующие траты и доходы получают `legacy = true`: они остаются для истории и лимитов, но баланс не двигают.
- «Отложено» в целях раскладывается в `goal_allocs`. Личная цель ложится на счёт владельца, семейная — по тем, кто
  откладывал (`goal_ops.by`); остаток без автора отдаётся создателю цели. Счёт выбирается в валюте цели, если такой
  есть, иначе берётся основной и сумма пересчитывается по текущему курсу. `goals.allocated` обнуляется, операции
  остаются как история.
- Снимки сверки не трогаются: они нужны для графика за 6 месяцев.

## Откат

Восстановление из бэкапа (`docs/restore.md`). Точечный откат не предусмотрен: после перехода новые записи
двигают балансы.
