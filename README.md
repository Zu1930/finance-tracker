# Траты по лимитам

Личный трекер расходов: ввод трат, месячные лимиты по категориям, копилки и график по месяцам.
Next.js 16 (App Router) + Upstash Redis, вход по одному паролю.

## Как хранятся данные

В Redis лежат JSON-документы: `settings`, `goals` и по одному документу на месяц (`m-2026-10`).
Схемы и миграций нет. API:

- `GET /api/data` — все документы разом
- `PUT /api/data/:doc` — записать один документ целиком
- `POST /api/import` — загрузить экспорт из версии в Claude
- `POST /api/login`, `POST /api/logout`

Все маршруты, кроме `/login`, закрыты `proxy.ts` (бывший middleware): он сверяет httpOnly-cookie
с хэшем от `APP_PASSWORD` и `SESSION_SECRET`. Смена любого из них разлогинивает все устройства.

## Деплой на Vercel

1. Залейте проект в GitHub и импортируйте репозиторий в Vercel (New Project). Настройки сборки по умолчанию.
2. В проекте на Vercel: **Storage → Create Database → Upstash for Redis** (Marketplace), бесплатный план,
   подключите к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами.
3. **Settings → Environment Variables**, добавьте:
   - `APP_PASSWORD` — пароль для входа;
   - `SESSION_SECRET` — длинная случайная строка (`openssl rand -hex 32`).
4. Сделайте Redeploy, чтобы переменные подхватились.
5. Откройте сайт, войдите по паролю. На экране настройки нажмите «Импорт из JSON» и выберите файл,
   скачанный из версии в Claude (кнопка «Экспорт в JSON» в настройках на странице «Лимиты»).
   Или начните с нуля, выбрав валюту лимитов.

На телефоне удобно добавить сайт на главный экран: в Safari «Поделиться → На экран „Домой“».

## Локальная разработка

```bash
npm install
npx vercel link && npx vercel env pull .env.local   # или заполните .env.local по .env.example
npm run dev
```

## Структура

```
app/
  (app)/            страницы за авторизацией: / (ввод), /limits, /goals, /chart
  api/              data, import, login, logout
  login/            страница входа
components/         TrackerProvider (состояние + очередь записи), экраны, импорт/экспорт
lib/                типы, утилиты, Redis, авторизация
proxy.ts            проверка сессии
```

Записи в один документ отправляются строго по очереди, интерфейс обновляется сразу, не дожидаясь ответа.
Если запись не прошла, появится сообщение с просьбой обновить страницу.
