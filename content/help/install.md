# Приложение на телефоне

Откройте сайт в браузере телефона и добавьте его на экран «Домой» — оно запустится как приложение, с уведомлениями.

- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

После первого запуска с экрана «Домой» пункт в карточке «Настройка» отметится сам.
